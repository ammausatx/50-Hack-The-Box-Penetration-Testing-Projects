# 50 Hack The Box Penetration Testing Projects

A practical, progressive portfolio of 50 authorized penetration-testing exercises using Hack The Box (HTB) machines and Academy labs. Every exercise includes a detailed README and three clearly labelled simulated training illustrations: workflow, findings, and validation.

> **Authorization:** Use only HTB-assigned targets, HTB Academy environments, retired machines you are authorized to test, or your own isolated replicas. Never run these commands against unrelated systems. Respect HTB rules and machine scope. No real credentials, third-party accounts, persistence, or out-of-scope pivoting.

## Learning paths

- Beginner: Projects 01–15
- Intermediate: Projects 16–35
- Advanced: Projects 36–50

## Toolset

Nmap, WhatWeb, Nikto, Gobuster, ffuf, Burp Suite, SQLmap, smbclient, enum4linux-ng, NetExec, BloodHound, Impacket, LinPEAS, WinPEAS, John the Ripper, Hashcat, Metasploit, and Netcat. Use automated output as leads; manually validate findings before reporting.

## Evidence and screenshots

Every project README embeds three project-specific simulated SVG training illustrations: workflow, findings, and validation (150 total). They are labelled as simulated visuals, not real HTB screenshots or proof of execution. Each guide also includes a checklist for adding your own redacted terminal, browser, or HTB lab screenshots after completing the exercise.

## Reporting standard

Record target identifier, assigned IP, timestamps, commands, relevant output, impact, severity rationale, remediation, and retest result. Redact flags, credentials, tokens, and personal data before publishing.
