# Project 47: Automated Enumeration Pipeline (Nmap + Web + LinPEAS/WinPEAS)

**Level:** Advanced  
**Environment:** HTB-assigned machine or Academy lab only

## Objective

Build a staged enumeration workflow that keeps every tool constrained to one HTB machine.

## Scope and authorization

Use only an HTB target explicitly assigned to your account or a dedicated authorized training environment. Read the lab rules and define exact hosts, actions, time window, and stop conditions. No real-world stealth, persistence, credential theft, or out-of-scope access.

## Prerequisites and tools

Nmap; WhatWeb; Gobuster/ffuf; LinPEAS or WinPEAS

- Dedicated lab VM and current HTB scope information.
- Evidence folder and written rules of engagement.
- Redact credentials, flags, tokens, and personal data from all evidence.

## Procedure

Require a manually entered assigned target and a scope confirmation before each stage. Run conservative Nmap discovery; only if web ports exist, run low-rate web fingerprinting; run local enumeration only after authorized lab access. Store separate outputs and review before progressing.

## Expected outcome

A staged workflow, explicit scope checkpoints, sanitized outputs, and a manual validation queue.
